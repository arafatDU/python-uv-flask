# Flask User CRUD API

This project is a **User CRUD API** built with Flask and SQLite. It provides endpoints to create, read, update, and delete user records. The project uses the **`uv` package manager** for managing the development environment.

## Features

- Create a new user
- Retrieve a user by ID
- Retrieve all users
- Update a user by ID
- Delete a user by ID
- SQLite database for persistent storage

## Requirements

- Python 3.7 or higher
- `uv` package manager
- Flask
- SQLite
